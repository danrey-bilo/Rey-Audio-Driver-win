# Rey Audio Driver

[English](README.md) | **Русский**

Аудиодрайвер, фоновая служба и микшер Windows 11 x64 для Rey Audio на Raspberry
Pi 5. USB и AoIP / LAN имеют отдельные ручные настройки. У каждой карты свои
сессия и микшер; выбор сверху меняет только отображение. Каталог вмещает до
десяти сохранённых карт.

**2.7.0 preview:** [EXE / MSI](https://github.com/danrey-bilo/Rey-Audio-Driver-win/releases/tag/v2.7.0-preview.1) ·
[Установка](docs/INSTALL.ru.md) · [Пары каналов Windows](docs/ENDPOINTS.ru.md) ·
[Архитектура и результаты](docs/REY-AUDIO-2.7.ru.md).

![Микшер Rey Audio](docs/assets/rey-mixer.png)

| | USB | AoIP / LAN |
|---|---|---|
| Подключение | Автоматическое обнаружение по постоянному DeviceId | Добавление Pi по IPv4 через панель в трее |
| Формат | 8×8, PCM16/24/32, шесть частот 44,1–192 кГц | Определяется Pi, до 8 входов и 8 выходов |
| Буферы | Ручная очередь передач и период аудио | Ручной блок, запас приёма и размер пакета |
| Транспорт | High-Speed interrupt, асинхронный WinUSB | UDP/IPv4, IOCP и ограничение работы по audio deadline |
| Выбор | USB можно явно выбрать для своей карты | По умолчанию после настройки LAN этой карты |

Для каждой карты 8×8 код ACX предусматривает системные входы/выходы
**1/2, 3/4, 5/6, 7/8** и полные многоканальные **1–8**. Они предназначены для
обычных приложений Windows и хостов WASAPI/KS. Один ID по USB и LAN — одна карта
с выбором транспорта. Разные карты имеют независимые тактовые домены;
синхронизированный агрегированный интерфейс пока не реализован.

Запустите **Rey-Audio-Setup-2.7.0-preview.1-x64.exe**: MSI находится внутри.
Установщик создаёт уникальный локальный тестовый сертификат, подписывает
SYS/CAT и удаляет временный закрытый ключ. Платный сертификат, signer и WDK
на клиентском ПК не нужны. **Нужен Test Mode Windows**. EXE предлагает явную
подготовку; пользователь перезагружает ПК самостоятельно. MSI не меняет
Secure Boot и изоляцию ядра. [Пошаговая инструкция](docs/INSTALL.ru.md) ·
[Варианты без Test Mode](docs/INSTALL-NORMAL-WINDOWS.ru.md).

Микшер: уровни, Mute, Solo, полярность, Master, реальные PCM-индикаторы
и счётчики перегрузки. Изменения не добавляют PCM-очередь и не перезапускают
транспорт. Профили и микшеры сохраняются отдельно по картам в реестре;
пользовательских INI и установочных скриптов нет.

Проверены **24 нативных контракта**, **12 коротких проверок службы с реальной Pi**,
30-секундное переключение на офлайн-карту при продолжающемся реальном USB-потоке,
содержимое MSI/EXE и локальная подпись. На стенде **одна физическая Pi**.
Загрузка ACX, фактические устройства Windows, Chrome/Telegram, несколько
реальных карт, установка/repair/uninstall с повышением и ADC/DAC ещё не
подтверждены. Пакет остаётся **Pre-release**.

Цель физического USB round-trip — **ниже 2 мс**. Предыдущий цифровой тест 299 с
дал RTT p50/p95/p99/max **373/410/419/944,2 мкс**, без Windows audio engine
и преобразователей. [Результаты USB](https://github.com/danrey-bilo/Pi5-AUSB/blob/v0.1.0/docs/RESULTS.md).

Зависимости: [Pi5-AUSB](https://github.com/danrey-bilo/Pi5-AUSB) и
[AoIP-lib](https://github.com/danrey-bilo/AoIP-lib), с прежней видимостью и
лицензиями. Служба и панель собираются без ASIO SDK. Неизменённый
[ASIO-релиз 2.5.0](https://github.com/danrey-bilo/Rey-Audio-Driver-win/releases/tag/v2.5.0)
остаётся доступен. Pi4 не обновлялась.
