# Rey Audio Driver

[English](README.md) · **Русский**

**USB-аудио, ASIO и микшер для одной Raspberry Pi 5 в Windows x64.**
Восемь входов и восемь выходов, целочисленный PCM16/24/32 и шесть частот
от 44,1 до 192 кГц. Служба подключает плату автоматически и продолжает работать
после закрытия окна микшера.

## Микшер

![Микшер одной USB-карты](docs/assets/rey-usb-only-mixer.png)

Восемь входных или восемь выходных каналов: уровень, Mute, Solo и полярность.
Master управляет воспроизведением. Индикаторы показывают реальные уровни PCM.
В панели три страницы — **Микшер**, **USB**, **Диагностика** — и доступ из трея.

## Запуск в Ableton

1. Скачайте из релиза **Rey-Audio-USB-ASIO-2.8.0-preview.1-x64.exe** и запустите.
   Подтвердите UAC: установятся ASIO-драйвер, автоматическая служба и панель/трей.
2. Подключите одну настроенную плату Pi5-AUSB по USB. Откройте **Rey Audio Driver**.
3. В Ableton **Settings → Audio** выберите **Driver Type: ASIO** и
   **Audio Device: Rey Audio USB ASIO**. Включите нужные входы и выходы.
4. Для документированного теста 192 кГц начните с **64 Samples**. Очередь USB
   и запас ASIO задаются вручную: [руководство по буферам](docs/BUFFER-GUIDE.ru.md).

USB-интерфейс обслуживает Microsoft WinUSB. Установочный INI, собственный
драйвер ядра, тестовый сертификат, Test Mode и изменение загрузки/защиты
не требуются. Перед обновлением полностью закройте DAW: она может удерживать
ASIO DLL. Смена формата и повторное открытие описаны в
[инструкции установки](docs/USB-ASIO.ru.md).

## Возможности

| Возможность | USB preview |
|---|---|
| Устройство | Одна Rey Audio USB; автоматическое обнаружение и постоянный ID |
| Каналы | 8 входов + 8 выходов |
| Форматы | PCM16, упакованный PCM24, целочисленный PCM32 |
| Частоты | 44,1 / 48 / 88,2 / 96 / 176,4 / 192 кГц |
| Транспорт | Pi5-AUSB, USB High-Speed interrupt, асинхронный WinUSB |
| Обработка | Ограниченные PCM-кольца, плавный gain, Mute/Solo/полярность, индикаторы |
| Буферы | Ручной блок/запас ASIO и очередь USB; автоподстройки нет |
| Автозапуск | Служба при загрузке Windows; панель/трей при входе |
| Настройки | Атомарный профиль USB/микшера в реестре; перенос прежних USB-настроек |
| Chrome / Telegram | Системные аудиоустройства Windows — отдельный этап проверки |

## Проверки

| Проверка | Результат именно этой сборки |
|---|---|
| Нативные контракты | **32/32 прошли** |
| Форматы PCM, блок64 / запас4 / очередь3 | **18/18 прошли**, по пять секунд на профиль |
| 192 кГц / PCM32, блок64 / запас4 / очередь3 | **295 с**, без capture drops и render late/missing frames |
| Цифровой RTT этого прогона, p50 / p95 / p99 / max | **1,6286 / 1,8837 / 2,0103 / 3,5171 мс** |
| Фактический темп кадров | **На 2,09% ниже номинального**; требует исследования |

В первой матрице с запасом3 были четыре FAIL; 295-секундный прогон с запасом3
также имел пропуски. Все результаты сохранены в
[отчёте](docs/USB-ONLY-2.8.ru.md) и
[машиночитаемых данных](docs/evidence/rey-usb-only-20261003.json).
Новую сборку проверял установленный нативный ASIO-host, а не Ableton.
На Pi использовалась цифровая петля; ADC/DAC не подключался.

**1,3802 мс** с запасом3 и **1,7135 мс** с запасом4 при 192 кГц/64/очередь3 —
расчёт заявленных ASIO-буферов. Эти числа не заменяют измеренный roundtrip.

Нужны Windows x64, C++17, CMake, .NET Framework 4.8, Pi5-AUSB и отдельно
полученные интерфейсные заголовки Steinberg ASIO. SDK в репозиторий не включён.
