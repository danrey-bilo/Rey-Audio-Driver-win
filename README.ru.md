# Rey Audio Driver

[English](README.md) | **Русский**

Windows 11 x64: собственный ACX/KMDF аудиодрайвер и фоновая служба для Pi5.
Главная страница **Микшер** содержит настройки восьми входов и восьми выходов.
У **USB** и **AoIP / LAN** отдельные страницы и ручные профили. USB находится
автоматически; LAN настраивается через панель в трее.

**2.6.1 preview:** [Скачать EXE / MSI](https://github.com/danrey-bilo/Rey-Audio-Driver-win/releases/tag/v2.6.1-preview.1) ·
[Установка](docs/INSTALL.ru.md) · [Микшер и задержка](docs/MIXER.ru.md) ·
[Устройство кода и сборка](docs/REY-AUDIO-2.6.ru.md).

![Микшер Rey Audio](docs/assets/rey-mixer.png)

| | USB | AoIP / LAN |
|---|---|---|
| Подключение | Автоматический поиск USB | Выбор и настройка Pi через трей |
| Формат | 8 входов + 8 выходов, PCM16/24/32, шесть частот 44,1–192 кГц | Формат от Pi, до 8 входов + 8 выходов |
| Буферы | Ручная очередь передачи и аудиоблок | Ручные block, guard и размер пакета |
| Передача | HS interrupt, асинхронный WinUSB | UDP/IPv4, IOCP RX, ограничение работы до deadline |
| Приоритет | Можно выбрать явно | По умолчанию после настройки LAN |

Запустите **Rey-Audio-Setup-2.6.1-preview.1-x64.exe**. Он содержит MSI и
проверяет совместимость Windows. Если Test Mode уже активен, достаточно обычной
установки с UAC. Иначе EXE предлагает явно включить Test Mode; после ручной
перезагрузки можно установить пакет. При необходимости Secure Boot отключается
в BIOS самостоятельно. MSI не меняет изоляцию ядра и не перезагружает ПК.
[Пошаговая инструкция](docs/INSTALL.ru.md).

Платный сертификат и внешние инструменты подписи на пользовательском ПК не нужны.
Установщик создаёт уникальный локальный тестовый сертификат, подписывает SYS/CAT,
добавляет доверие к его публичной части на этом ПК и удаляет временный закрытый
ключ. Для экспериментального kernel-драйвера Windows всё равно требует Test Mode.
Служба сохраняет настройки в реестре; новый пакет устанавливается без INI и
скриптов установки.

В микшере есть gain, Mute, Solo, полярность, общий уровень выходов, реальные
пиковые уровни PCM и счётчики clipping. Обработка выполняется в текущем callback
без дополнительной очереди PCM. Пройдены 14 проверок контрактов/DSP и 10 конечных
проверок службы с реальным Pi. Проверены локальная подпись, каталог и отказ после
повреждения SYS. [Результаты и оставшиеся проверки](docs/REY-AUDIO-2.6.ru.md#проверки).

Ранний 299-секундный USB-прогон 8×8/192000/32 измерил цифровой RTT
p50/p95/p99/max **373/410/419/944,2 мкс**. Физическая аудиозадержка туда и обратно
ниже **2 мс** — цель: установленный ACX/WASAPI, независимый аппаратный такт и
ADC/DAC loopback её ещё не подтвердили. Это **Pre-release**.
[USB-измерения](https://github.com/danrey-bilo/Pi5-AUSB/blob/v0.1.0/docs/RESULTS.ru.md).

Отдельные зависимости [Pi5-AUSB](https://github.com/danrey-bilo/Pi5-AUSB) и
[AoIP-lib](https://github.com/danrey-bilo/AoIP-lib) сохраняют видимость и лицензии.
Служба и панель собираются без ASIO SDK. Неизменённый
[ASIO-релиз 2.5.0](https://github.com/danrey-bilo/Rey-Audio-Driver-win/releases/tag/v2.5.0)
доступен на время перехода. Поддерживается один Pi; несколько плат отложены.
Pi4 не обновляется.
