# Ручные буферы USB-ASIO

Блок ASIO: 16, 32, 64, 128, 256 кадров. Запас отправки: 1–4 блока.
Очередь USB: 1–16 пакетов. Значения независимы, меняются вручную;
автоматического выбора «самого быстрого» режима нет.

При 192000 Гц, USB depth3:

| Блок / lead | Заявленная сумма |
|---|---|
| 64 / 3 | 1,3802 мс |
| 64 / 4 | 1,7135 мс |
| 32 / 3 | 0,8802 мс |
| 16 / 4 | 0,7135 мс |

Это значения из ASIO getLatencies, а не измеренная аналоговая петля.
Меньший буфер сокращает время на пробуждение host и повышает риск пропусков.
При меньшей частоте тот же блок длится дольше. Прежние короткие успехи 16/32
не доказывают стабильность; более длинные испытания содержали ошибки.
Результаты текущей сборки: [отчёт 2.8](USB-ONLY-2.8.ru.md).

USB → «Сохранить ASIO», затем заново откройте драйвер в Ableton. Очередь,
частота и PCM применяются отдельно кнопкой «Применить USB» после закрытия ASIO.
Проверяйте свой проект, число пропусков/опозданий, переполнение, непрерывность
кадров и RTT. Один прогон — максимум 295 секунд. Хорошая медиана при пропусках
не означает стабильный профиль. Перед сравнением проверяйте generation и
connection_id. Уменьшение depth2 уже давало замедление цифрового стенда;
нулевого счётчика ошибок для выбора недостаточно.
