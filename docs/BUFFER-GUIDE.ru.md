# Ручной выбор буферов

На главном экране **ASIO buffer** и **LAN buffer** задаются в сэмплах. Подписи длительности вычисляются для выбранной частоты. При 192 кГц 64 сэмпла — 0,333 мс, 384 — 2,000 мс. Это размеры буферов, а не измеренный круговой тракт.

1. Выберите частоту, разрядность и используемые каналы.
2. Начните с достаточно больших ASIO/LAN-буферов и типового проекта DAW.
3. Не меняя ASIO, постепенно уменьшайте LAN. Следите за missing/late, RX gap, переполнением очередей, TX/deadline errors.
4. Найдя рабочий LAN для этой нагрузки, зафиксируйте его и уменьшайте ASIO. Дополнительно проверяйте callback/host overruns.
5. При росте ошибок верните последнее чистое значение и проверьте его на самой тяжёлой обычной нагрузке достаточно долго.

Автоматического подбора нет. Чистые пять минут подтверждают только это окно, а не все проекты и ПК. Сохраняйте профиль, длительность, p50/p95/p99/max цифрового RTT и счётчики ошибок вместе. Настройки универсальные: драйвер не применяет изменения питания сетевой карты, IRQ и глобального планировщика Windows.

Открывайте **Diagnostics** из панели драйвера в DAW. Отдельное окно из трея не читает счётчики другого ASIO-процесса. Физическая задержка ADC/DAC требует аппаратного бэкенда и подключённого loopback.
