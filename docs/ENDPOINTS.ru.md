# Карты и аудиоустройства Windows

У каждой карты Rey — собственные микшер, профили USB/LAN и аудиосессия.
Все подключённые карты работают одновременно. Выбор сверху **Микшера** меняет
только отображаемую карту и её настройки. Каталог рассчитан на десять карт,
включая сохранённые отключённые устройства.

## Пары каналов в системе

Для карты 8×8 в реализации ACX предусмотрено десять аудиоустройств:

| Вход Windows | Выход Windows | Каналы карты |
|---|---|---|
| Rey Audio `<ID>` Input 1/2 | Rey Audio `<ID>` Output 1/2 | 1 и 2 |
| Rey Audio `<ID>` Input 3/4 | Rey Audio `<ID>` Output 3/4 | 3 и 4 |
| Rey Audio `<ID>` Input 5/6 | Rey Audio `<ID>` Output 5/6 | 5 и 6 |
| Rey Audio `<ID>` Input 7/8 | Rey Audio `<ID>` Output 7/8 | 7 и 8 |
| Rey Audio `<ID>` Input 1-8 (Multichannel) | Rey Audio `<ID>` Output 1-8 (Multichannel) | Все восемь |

`<ID>` — последние восемь символов постоянного DeviceId. Полный ID из 32 символов
определяет владельца сессии и контейнер устройства Windows. Разные карты
различаются даже при одинаковой частоте и разрядности.

Это обычные устройства записи и воспроизведения Windows: они предназначены
для списка в **Параметры → Система → Звук**, диспетчера устройств, браузеров и
приложений связи. В Windows или приложении выберите **Input 1/2** как микрофон
и нужную пару **Output** для воспроизведения. Кнопка **Звук Windows** в панели
открывает настройки системы. Для записи нужен разрешённый доступ к микрофону
в параметрах конфиденциальности Windows. Установщик не меняет системные
динамики и микрофон по умолчанию автоматически.

Полный интерфейс 1–8 выбирается в приложении, поддерживающем WASAPI/KS и восемь
каналов. Доступная задержка зависит также от аудиорежима и буферов самой DAW.
В общем режиме Windows может пересчитывать частоту приложения в формат карты.
Реальные периоды и режимы необходимо проверить после загрузки драйвера.
Низкая задержка USB-транспорта не гарантирует <2 мс в Chrome или Telegram.

Входная пара читает соответствующие каналы текущего блока. Выходная пара пишет
в свой диапазон каналов. Полный выход и отдельная пара могут работать вместе:
их PCM суммируется с ограничением по допустимой разрядности. Если сумма
перегружается, уменьшите уровни источников. Выходной микшер карты и Master
применяются после суммирования один раз. Отдельная PCM-очередь для разделения
каналов не добавляется.

## Подключение и выбор

1. USB обнаруживается автоматически; при открытии проверяется постоянный ID.
2. Для LAN введите IP в **AoIP / LAN** и нажмите **Подключить**. До добавления
   карты служба читает её идентификатор без подписки на аудиопоток.
3. Одинаковый ID по USB и LAN относится к одной карте. Настроенный LAN имеет
   приоритет; **Использовать USB** меняет транспорт этой карты. Смена транспорта
   перезапускает её сессию. Остальные карты продолжают работать.
4. Активным LAN-картам нужны разные локальные UDP-порты. Конфликт отклоняется.
   Служба обновляет только своё правило firewall с Private/LocalSubnet.
5. Выбор сверху меняет только отображение. Все команды микшера и профилей
   адресуются показанной карте. Отключённый ненужный профиль можно удалить:
   **Диагностика → Забыть отключённую карту**.

У отдельных карт свои тактовые домены и временные шкалы. Одновременная работа
не создаёт синхронизированную агрегированную карту; синхронизация и компенсация
дрейфа для такого режима требуют отдельной реализации.

## Что проверено

Сборка драйвера, INF и каталог проходят проверки. Разделение стереопар,
суммирование и ограничение PCM проверены нативными тестами. На стенде есть
**одна физическая Pi**. В 30-секундном тесте выбор переключался на сохранённую
офлайн-карту: цифровой USB-поток реальной Pi продолжался без смены поколения
сессии, а настройки оставались независимыми. Это не проверка двух физических Pi.

**ACX на данном ПК ещё не загружен.** Появление и названия устройств в Windows,
одновременная работа реальных endpoints, Chrome/Telegram, жизненный цикл ядра,
Verifier, сон/возобновление и физическая задержка ADC/DAC пока не подтверждены.
Изображение — фактический интерфейс с одной Pi; отсутствие драйвера явно
показано в панели. Пакет остаётся **Pre-release**.
