# Обычные аудиоустройства Windows

Текущий USB-ASIO EXE предоставляет Ableton/ASIO **8 входов и 8 выходов**.
Он **не устанавливает** системные микрофоны/динамики для Chrome и Telegram.
Панель явно показывает ASIO-режим; кнопка «Звук Windows» недоступна.

Нужный сценарий — один установщик Rey, автоматическое подключение и всё
управление в Rey. Четыре стереовхода и четыре стереовыхода Windows соответствуют
каналам 1–2, 3–4, 5–6 и 7–8. Связывание регуляторов MONO/STEREO в микшере
и создание системных аудиоустройств — отдельные операции.

## Собственный компонент Rey

Исходники ACX теперь создают ровно восемь стереоустройств, без дополнительных
устройств 1–8. У моста независимые фазы захвата и воспроизведения: публикация
входа AUSB и последующий сбор выхода не продвигают время потока дважды.
Для ABI 2 нужны согласованные служба и драйвер ядра. Пакет собирается и проходит
проверки INF/каталога. SYS и CAT не подписаны и не загружались. Проверки
отображения каналов не заменяют загрузку драйвера и проверку WASAPI.

## Интеграция готового драйвера

[Thin Audio Gateway](https://software.muzychenko.net/en/thin-audio-gateway/)
предоставляет прямой API общей памяти. Таким компонентом может управлять
служба Rey, которая задаёт время и маршруты аудио; отдельная программа
маршрутизации пользователю не нужна. Поставщик делает заказные конфигурации.
Для четырёх пар требуется подписанный пакет с восемью стереолиниями.
Ранее проверенное demo создало одну многоканальную пару записи/воспроизведения;
создание дополнительных линий завершилось ошибкой. Готовым решением на
восемь системных устройств оно не является.

Во время проверки 16 октября установлен официальный пробный VB-Audio Matrix;
его драйвер с подписью Microsoft загрузился. Программа открыла Rey ASIO,
поэтому другой host не может одновременно открыть это прямое ASIO-соединение.
Полная маршрутизация четырёх пар и её задержка не проверены. Пробная установка
удалена после уточнения требования об интеграции. Matrix не входит в Rey
и не добавлен в его автозапуск.

Текущий USB-ASIO установщик по-прежнему не содержит системный аудиодрайвер.
Для полного сценария с одним установщиком нужен производственный подписанный
пакет Rey или подходящий подписанный OEM-компонент, затем проверка установки,
всех каналов, одновременной работы Windows/ASIO и переподключений.
Прямой ASIO остаётся отдельным от буферизации общего аудиодвижка Windows.
