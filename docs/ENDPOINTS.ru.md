# Стереовходы и стереовыходы Windows

В **2.8.2-akm-dev.7** встроен готовый подписанный [Synchronous Audio Router 0.13.1](https://github.com/eiz/SynchronousAudioRouter/releases/tag/v0.13.1). Один установщик Rey автоматически создаёт четыре стереовхода и четыре стереовыхода: **Input / Output 1-2, 3-4, 5-6 и 7-8 (Rey Audio)**. Внешняя программа маршрутизации, ASIO-обёртка SAR и сетевой фильтр не устанавливаются.

Всё управление остаётся в Rey. Переключатели MONO/STEREO связывают регуляторы, сохраняя раздельные отсчёты и индикаторы L/R. Прямой ASIO предоставляет 8 входов и 8 выходов и работает параллельно с Windows. Воспроизведение Windows и ASIO суммируется перед выходным микшером с ограничением диапазона PCM.

## Передача звука

Приложение Windows → стереопара WaveRT → общая память Rey → микшер → собственный AUSB → Pi. Запись идёт в обратном направлении. USB принадлежит службе Rey; оба API следуют аппаратным часам платы. Без потоков Windows/ASIO аудиообмен останавливается, управление остаётся доступным.

Пары используют PCM32 и текущую частоту USB; сам USB поддерживает PCM16/24/32. Частоты: **44,1 / 48 / 88,2 / 96 / 176,4 / 192 кГц**; комбинированный режим ограничен 96 кГц. Частоту меняют в Rey. У SAR разные идентификаторы Windows для разных частот; затронутые приложения нужно переоткрыть. Идентификатор ASIO не меняется.

На стенде общий аудиодвижок Windows сообщил период **10 мс**. Результат ASIO ниже 5 мс относится к отдельной цифровой USB-петле и не означает такую же задержку обычных приложений Windows или аналогового тракта АЦП/ЦАП.

## Установка и ограничения

Неизменённые SYS/INF/CAT, контрольные суммы, уведомления авторов и архив соответствующих исходников включены в пакет. Установщик управляет только `ROOT\REYAUDIO_SAR\0000` и не перехватывает другую установку SAR. Через SetupAPI заранее создаются свойства `EP`: старый SAR пишет `MSEP`. Подписанные файлы не изменяются. См. [описание Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/implementing-audio-processing-objects).

Драйвер с прежней перекрёстной подписью загрузился в Windows 11 build 26300, где Secure Boot и целостность памяти **уже были отключены**. Совместимость с более строгой политикой защиты пока не подтверждена. Установщик не меняет защиту или загрузку Windows. При отказе нового драйвера выполняется откат созданного устройства и файлов/службы Rey. Удаление убирает только корневое устройство Rey, сохраняя общий пакет драйвера и настройки платы.

[Отчёт](WINDOWS-PAIRS-2026-10-17.ru.md) и [данные](evidence/rey-windows-pairs-20261017.json) отдельно описывают синтетическую и настоящую USB/JACK-петлю. АЦП/ЦАП, длительная нагрузка DAW, exclusive WASAPI, сон и физическое переподключение для этой сборки не проверены. Сборка остаётся предварительной.

Неподписанный ACX Rey и прежний прототип TAG сохранены для исследований, но этот установщик их не использует. Пробный Matrix удалён и в Rey или автозапуск не включён.
