# API одной USB-карты

Локальный pipe: `\.pipeReyAudio.Control.v1`. Управление — ограниченные
ASCII-запросы/JSON; PCM передаётся через анонимную общую память и событие.
Служба проверяет PID владельца ASIO и дескрипторы IPC.

| Запрос | Действие |
|---|---|
| `STATUS` | USB/ASIO, ID, формат, счётчики, микшер и события |
| `USB rate bits depth block guard automatic` | Ручной USB-профиль; изменения параметров перезапускают поток |
| `MIX direction:channel gain mute solo polarity apply` | Канал 0–7; направление 0 — вход, 1 — выход |
| `MASTER gain mute` | Master всех выходов |
| `MIX_RESET` | 0 dB; Mute/Solo/полярность выключены |

Gain — сотые dB со смещением 6000: 6000 = 0 dB, 5800 = −2 dB.
Предел канала 0–7200, Master 0–6600; флаги 0/1. Глубина USB 1–16,
блок 16/32/64/128/256, guard 0–8192; шесть частот и PCM16/24/32.
Перед сменой USB-формата остановите ASIO. Микшер работает без перезапуска.

Ответ содержит `version`, `identity`, `device_limit:1`, `device_warning`,
`usb`, `active`, `stats`, `asio`, `mixer`, `events`. `route` — только `usb`
или `none`. Поля `lan`, `preferred`, `devices`, `selected_device` удалены.
Прежние команды поиска, маршрута и выбора карт отклоняются без изменения
настроек. При ошибке возвращается `ok:false` и сообщение `error`.

Внутренние ASIO-запросы INFO/OPEN/CLOSE/RATE допускают auto или точный ID
текущей карты для защиты от переподключения к другому устройству. Один host
владеет соединением. ABI IPC 1 и проверка размера структуры сохранены.

Для сравнения счётчиков учитывайте `generation` USB и `connection_id` ASIO.
Нулевой счётчик ошибок сам по себе не доказывает RTT, частоту реального
потока или задержку ADC/DAC. [Полное описание](API.md).
