# Установка USB-версии

Используйте **Rey-Audio-USB-ASIO-Setup-x64.exe**, подтвердите UAC.
[Подробная инструкция и поля Ableton](USB-ASIO.ru.md).

Подключение одной USB-карты автоматическое; настройки и микшер — в
`%ProgramFiles%\ReyAudio\USBASIO\ReyAudioControl.exe`. Служба запускается
при старте ПК; трей — при входе пользователя. INI и ручная установка INF
не требуются. Новый SYS, сертификаты и Test Mode не используются.

Перед обновлением полностью закройте DAW. USB-профиль и микшер сохраняются
при переходе со старой версии. Сетевые настройки и выбор карт не переносятся
в активную конфигурацию. Системные устройства Windows для браузеров/связи
ещё являются отдельным этапом; пакет предоставляет ASIO 8×8.

Ранее опубликованный ACX 2.7 MSI не является установщиком текущего USB-ASIO.
Его инструкции сохранены в истории и не применяются к этому EXE.
