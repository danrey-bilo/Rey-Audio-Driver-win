# Rey Audio USB ASIO — версия разработки для AKM

Одна Raspberry Pi 5, восемь входов и восемь выходов, PCM16/24/32.
Частоты: **44,1 / 48 / 88,2 / 96 / 176,4 / 192 кГц**. 384 кГц убраны.

Установщик **Rey-Audio-USB-ASIO-Setup-x64.exe** обновляет службу, ASIO и панель
управления. Для установки требуется подтверждение Windows UAC. Перед обновлением
закрой DAW: она может удерживать ASIO DLL. Все четыре файла должны быть одной
сборки. Установщик проверяет хеши и сохраняет настройки.

На Pi нужна соответствующая версия Rey Effects с собственным USB-транспортом.
Обычный звук Windows работает через отдельную функцию UAC2; ASIO использует
WinUSB и получает приоритет на время потока. Новый SYS-драйвер и Test Mode не нужны.

## Управление

В **Устройстве** доступны **Аудиокарта** и **Комбинированный** режимы.
Эффекты работают только до 96 кГц. В режиме аудиокарты обработка выключена.
Без USB Pi автоматически становится процессором эффектов; при подключении
возвращает последний режим ПК и маршруты каналов. В вебе переключателя нет.

Формат содержит только **частоту**, **буфер** и **разрядность**. Пакеты USB и
запас очередей драйвер выбирает сам по частоте. Старые ручные параметры очередей
не применяются. Размер буфера можно выбирать и из DAW; ASIO 16 сэмплов
соответствует периоду JACK 32. Начальный вариант — 64 или 128, затем проверка
своего проекта.

В раскрываемых маршрутах каждого канала выбираются отправка на ПК до/после
эффектов и возврат с ПК прямо на ЦАП/через эффекты.

1. Останови аудиодвижок DAW перед сменой частоты, разрядности или режима.
2. Примени формат в Rey и выбери **Rey Audio USB ASIO** в DAW.
3. После отключения USB или обновления драйвера открой ASIO заново.

Панель запускается в трей при входе в Windows. Значок остаётся доступным при
отключённом USB; Windows может поместить его среди скрытых значков.

## Задержка и проверки

В диагностике есть счётчики очередей и callback. Расчёт буферов ASIO не включает
Pi/JACK, согласование часов и АЦП/ЦАП; это не измеренная сквозная задержка.
Цифровой проход USB → JACK → USB измеряется отдельно. Период USB 125 мкс
не равен задержке всей звуковой цепи.

Старые результаты цифрового стенда сохранены в [отчёте 2.8.1](USB-LATENCY-2.8.1.md).
Версия остаётся разработческой: транспортные прогоны не заменяют аналоговую
петлю и длительную работу конкретного проекта DAW.

Для сборки выполни `git submodule update --init --recursive` и отдельно подготовь
Steinberg ASIO SDK. SDK не распространяется с проектом. Сборка
`REY_FINITE_QUALIFICATION=ON` изолирована от установленной службы, не регистрирует
DLL и не принимается упаковщиком как устанавливаемый драйвер.
