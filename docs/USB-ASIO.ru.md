# Установка Rey Audio USB ASIO 2.8.1

Одна USB-плата, 8 входов и 8 выходов, PCM16/24/32, 44,1–192 кГц.
Запустите **Rey-Audio-USB-ASIO-2.8.1-preview.1-x64.exe** и подтвердите UAC.
Устанавливаются x64 ASIO DLL, автоматическая служба и микшер/трей в
`%ProgramFiles%\ReyAudio\USBASIO`. USB обслуживает Microsoft WinUSB.
Новый SYS, тестовый сертификат, Test Mode, INI и смена загрузки/защиты не нужны.
Системные микрофоны/динамики Chrome/Telegram — [отдельный этап](ENDPOINTS.ru.md).

Подключите одну настроенную Pi5-AUSB; USB определяется автоматически. Откройте
**Rey Audio Driver → USB**. Для описанных проверок на Pi нужен runtime 0.1.1.
Карту обслуживает один ASIO-host. Сохранённые ручные параметры сохраняются.

## Настройки Ableton

| Поле | Проверенный в Ableton профиль |
|---|---|
| Driver Type | ASIO |
| Audio Device | Rey Audio USB ASIO |
| In/Out Sample Rate | 192000 Hz или 96000 Hz |
| Buffer Size | 64 Samples на 192 кГц; 32 на 96 кГц |
| Hardware Setup | Rey → USB → параметры ASIO |
| Запас отправки ASIO | 3 блока; проверяйте свой проект |
| Формат USB | PCM32, очередь4 |

До выбора минимального буфера изучите [измерения и реальные наблюдения Ableton](USB-LATENCY-2.8.1.ru.md).
Если deadline-счётчики растут, увеличьте запас вручную. Очередь USB и ASIO-блок/
запас — отдельные настройки.

1. В Ableton выберите **No Device** перед сменой частоты/PCM/очереди USB.
2. Примените USB в Rey. Выберите блок и запас ASIO, нажмите **Сохранить ASIO**.
3. Снова выберите **Rey Audio USB ASIO**. Проверьте частоту и Buffer Size.

Панель различает работающие и выбранные настройки. Сохранение действует при
следующем открытии ASIO. После потери/повторного появления USB или смены формата
заново откройте ASIO.

Расчёт задержки в кадрах:
`input = N + depth × ceil(rate / 8000)`, `output = (lead − 1) × N + 1`.
При depth4/lead3 профиль 192 кГц/64 сообщает **1,5052 мс**, 96 кГц/32 —
**1,5104 мс**. Это расчёт буферов. Цифровой RTT иногда превышает 3 мс;
физическая задержка ADC/DAC не измерена. 125 мкс микрокадра не означают полную
задержку аудио 125 мкс. [Буферы](BUFFER-GUIDE.ru.md).

## Обновление и удаление

Полностью выйдите из Ableton перед заменой ASIO DLL: No Device может удерживать DLL.
Установщик проверяет SHA256 и заменяет только изменившиеся файлы своей установки.
Идентичная DLL не переписывается при обновлении службы/панели. Локально проверено
обновление финальной службы/панели при удерживаемой неизменённой DLL; изменённая
DLL остаётся заблокированной до выхода из host.

Установщик регистрирует COM/ASIO и `ReyAudioService --service --asio-only`,
включает автозапуск службы/трея, сохраняет профиль и откатывает ошибки замены.
Прежние USB/микшер-настройки переносятся без включения сетевого транспорта.
Удаление доступно в «Установленных приложениях»; профиль сохраняется.
Установка/обновление проверены локально, удаление и физический hotplug ещё не квалифицированы.
