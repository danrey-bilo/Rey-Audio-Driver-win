# Rey Audio USB ASIO 2.8

Одна USB-карта, 8 входов и 8 выходов, PCM16/24/32 и шесть частот
44,1–192 кГц. Активный Windows-драйвер больше не содержит AoIP/LAN,
многокарточного каталога или привязки ASIO к выбранной карте.

Запустите **Rey-Audio-USB-ASIO-Setup-x64.exe**, подтвердите UAC. Устанавливаются
пользовательская ASIO DLL, автоматическая служба и панель/трей в
`%ProgramFiles%\ReyAudio\USBASIO`. Транспорт использует Microsoft WinUSB.
Новый SYS, сертификаты, Test Mode и изменение загрузки/защиты не нужны.
Демо TAG не требуется. Этот пакет не создаёт системные микрофоны/динамики
для Chrome/Telegram — это [отдельный этап](ENDPOINTS.ru.md).

Подключите одну Pi5 по USB; она определяется автоматически. Откройте
`ReyAudioControl.exe`: Микшер / USB / Диагностика. У карты один ASIO-host.
На странице USB параметры меняются вручную. Для начальной проверки оставьте
192000 Гц, PCM32, очередь USB 3 и ASIO-блок 64. Выбор запаса 3/4 необходимо
сверять с [результатами именно этой сборки](USB-ONLY-2.8.ru.md).

В Ableton Settings → Audio:

| Поле | Значение |
|---|---|
| Driver Type | ASIO |
| Audio Device | Rey Audio USB ASIO |
| In/Out Sample Rate | 192000 Hz для профиля малой задержки |
| Buffer Size | 64 Samples для начальной проверки |
| Hardware Setup | Панель Rey, USB → параметры ASIO |

После «Сохранить ASIO» заново выберите драйвер в Ableton. До смены частоты,
разрядности или очереди закройте ASIO в host, затем примените USB и откройте
его снова. После потери/повторного появления USB тоже заново откройте ASIO.
Для замены DLL при обновлении полностью выйдите из Ableton: No Device
может оставлять DLL в памяти. Установщик проверяет блокировки до замены.

ASIO возвращает целые входные/выходные кадры задержки:
`input = N + depth × ceil(rate / 8000)`, `output = (lead − 1) × N + 1`.
При 192000/64/depth3/lead3 это 136 + 129 кадров, **1,3802 мс**;
с lead4 — 136 + 193, **1,7135 мс**. Это расчёт буферов, а не измерение
аналоговой петли. 125 мкс микрокадра USB не равны полной задержке аудио.
[Руководство по буферам](BUFFER-GUIDE.ru.md).

Установщик проверяет SHA256 четырёх встроенных файлов, регистрирует x64
COM/ASIO и службу `ReyAudioService --service --asio-only`, включает автозапуск
службы и трея. Он заменяет только принадлежащую этому пакету установку;
ошибки замены приводят к откату. Старые настройки USB/микшера переносятся в
единый профиль. Сетевая часть при переносе не включается.

Удаление доступно в списке установленных программ. Профиль сохраняется;
журнал и запущенный установщик могут остаться в папке установки.
Установка и обновление проверены локально; сценарий удаления ещё не
квалифицирован. Текущий EXE отличается от исторического ACX MSI 2.7.

Доказательства: [отчёт 2.8](USB-ONLY-2.8.ru.md),
[историческая цифровая проверка ASIO/Ableton](evidence/rey-usb-asio-20261003.json),
[испытания меньших буферов предыдущей сборки](evidence/rey-usb-asio-low-buffer-20261003.json).
Успех предыдущей сборки не переносится автоматически на 2.8.
Физические ADC/DAC и аналоговая задержка пока не измерены.
