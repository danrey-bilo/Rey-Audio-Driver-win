# Проверки 2.4.3

Чистая Release-сборка Windows x64 и четыре CTest прошли. Выполнены 12 скрытых рендеров шести экранов при двух масштабах шрифта; проверены переходы, видимость и нижние кнопки. Windows Shell извлёк две группы значков EXE и одну DLL. В MSI подтверждены версия 2.4.3, английский интерфейс, пять файлов, индексы значков 0/1, значок списка приложений и отсутствие автоподбора.

Установочные пакеты проверены как файлы; новую установку и длительный аудиопрогон этот выпуск не проходил. Числа задержки из датированных исторических отчётов не являются результатом 2.4.3. Физический ADC/DAC-бэкенд не реализован.
