# Rey Audio Driver 2.8.0 USB preview

Тег: **v2.8.0-usb-preview.1** · Windows x64 · одна USB-карта · 8×8.

Этот релиз переводит Rey Audio Driver только на USB. Служба, ASIO и микшер
работают с одной платой Pi5-AUSB. Сетевой транспорт и управление несколькими
картами выведены из активного кода; прежние релизы AoIP сохранены.

## Изменения

- Одна USB-сессия, автоматическое обнаружение и постоянный ID платы.
- Микшер, USB и Диагностика; страницы LAN и переключателя карт нет.
- PCM16/упакованные24/int32, 8 входов и 8 выходов, шесть частот 44,1–192 кГц.
- Ручной блок/запас ASIO и очередь USB.
- Атомарный профиль USB/микшера с переносом прежних настроек.
- Отдельный EXE: ASIO, автоматическая служба Windows и панель/трей.
- Собственный драйвер ядра, INI, тестовый сертификат и Test Mode не нужны.
- Сборка не зависит от AoIP-lib, Winsock, IOCP и настройки брандмауэра.

## Проверки и ограничения

32/32 нативных контракта прошли. Установленный COM/ASIO проверен во всех
18 форматах PCM с блоком64/запасом4/очередью3. Прогон 295 секунд при
192 кГц/PCM32 прошёл без capture drops и render late/missing frames.
Цифровой RTT p50/p95/p99/max: **1,6286 / 1,8837 / 2,0103 / 3,5171 мс**;
темп кадров **на 2,09% ниже номинального**. Прежние FAIL сохранены.

**Pre-release:** номинальный аудиотакт, стабильный RTT ниже 2 мс, Ableton
после переделки, физические ADC/DAC, удаление и физическое переподключение
ещё требуют проверки. Звук Windows для Chrome/Telegram — отдельный этап.
Тесты использовали цифровую петлю Pi.
