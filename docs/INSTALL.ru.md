# PiAoIP 2.4.3 — установка Windows

Драйвер соединяет 64-битный ASIO-хост Windows 11 x64 с совместимым сервисом Pi. Системные устройства микрофона/динамиков не создаются. Панель, трей, установщик и установленная справка — на английском.

## Установка

1. Закройте ASIO-хосты и PiAoIP в трее.
2. Запустите `PiAoIP-2.4.3-Windows11-x64.msi`. Администратор нужен для установки, регистрации ASIO и правила входящего UDP 50021 в локальной подсети.
3. Соедините ПК и Pi через Gigabit Ethernet, задайте доступные друг другу IPv4-адреса. Пример: ПК `192.168.50.1/24`, Pi `192.168.50.2/24`, без шлюза/DNS на аудио-LAN. Адреса не зашиты в драйвер.
4. На Pi задайте адрес ПК: `sudo piaoip-configure --interface eth0 --peer 192.168.50.1 --restart`.
5. Откройте **PiAoIP Settings → Device → Find and connect**, найдите Pi или введите её IPv4.
6. Задайте **Sample rate**, **Bit depth**, **ASIO buffer**, **LAN buffer** и нажмите **Apply**.
7. В DAW выберите **Pi AoIP**. После изменения настроек переоткройте аудиодвижок, если хост не выполняет ASIO reset.

## Меню

| Меню | Возможности |
|---|---|
| Device | Поиск, подключение и выбор используемых каналов |
| Settings | Главные настройки и сокращение трафика при цифровой тишине |
| Diagnostics | Счётчики потока и цифровой RTT |

Физическое число каналов приходит от Pi. Отметки выбирают используемые каналы. Буферы настраиваются вручную, помощник автоподбора удалён. Подписи длительности вычисляются как `сэмплы × 1000 / частота` и не измеряют полный аудиотракт.

Счётчики доступны из панели работающего ASIO-экземпляра: открывайте её из DAW. RTT требует PCM32 и маршрута выбранный вход → одноимённый выход без эффектов. Избегайте акустической обратной связи.

## Настройки и обновление

Профиль: `%LOCALAPPDATA%\PiAoIP\PiAoipAsio.ini`. При обновлении значения сохраняются. Для точного отката сделайте копию INI при закрытых ASIO-хостах. После ручного изменения буферов проверяйте проект на missing/late/deadline misses.

В **Установленные приложения → PiAoIP** доступны восстановление и удаление. В 2.4.3 добавлены встроенные значки настроек/справки, явные значки ярлыков меню «Пуск» и списка приложений. Windows может кратковременно сохранять старый вид ярлыка до обновления кэша Проводника.

Windows ARM64, Server и 32-битные ASIO-хосты не поддерживаются этим пакетом. Pi требует отдельный сервис и RT-ядро. MSI не настраивает сетевые карты, affinity, питание Windows, виртуальные машины и ОС Pi.

## Состав

`PiAoipAsio.dll`, `PiAoipControl.exe`, инструкция, `PROJECT-LICENSE.txt`, `ASIO-SDK-LICENSE.txt`. Steinberg SDK и инструменты тестирования в MSI не входят. Условия проекта и ASIO действуют отдельно. Пакет не подписан, если распространитель не добавил подпись.
