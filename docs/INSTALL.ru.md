# Установка Rey Audio Driver 2.6.1 preview

Запустите **Rey-Audio-Setup-2.6.1-preview.1-x64.exe**. Он содержит MSI внутри;
распаковывать ZIP, запускать PowerShell и редактировать INI не требуется.
Для уже подготовленного компьютера можно запустить MSI напрямую.
Поддерживается Windows 11 x64 22H2 и новее, .NET Framework 4.8.

## Подготовка Windows один раз

Собственный ACX является драйвером ядра. Windows не разрешает новому локально
подписанному kernel-драйверу работать в обычном защищённом режиме. Подпись MSI
это правило не меняет. Платный или заранее полученный сертификат проекту не нужен:
установщик создаёт локальную тестовую подпись именно на вашем компьютере.
[Правила загрузки Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/the-testsigning-boot-configuration-option).

1. Запустите EXE. Он проверит текущую политику Windows до установки.
2. Если **Secure Boot включён**, отключите его в BIOS/UEFI: обычно раздел
   **Security** или **Boot**, параметр **Secure Boot → Disabled**. Названия зависят
   от платы. Установщик не меняет настройки BIOS.
3. Нажмите **Включить Test Mode…**, подтвердите описание изменения и запрос UAC.
   Эта кнопка меняет только TESTSIGNING для следующей загрузки Windows.
4. Перезагрузите ПК самостоятельно. Установщик не перезагружает компьютер.
5. Повторно откройте EXE → **Установить**, подтвердите UAC и завершите мастер.

Если Test Mode уже активен, шаги подготовки не нужны: EXE/MSI → UAC → установка.
При BitLocker перед изменением загрузки нужен доступ к своему ключу восстановления.
При возврате обычной политики сначала удалите Rey Audio Driver, затем выключите
Test Mode и верните Secure Boot; это отдельное явное действие владельца ПК.

**Изоляцию ядра заранее отключать не требуется.** SYS получает встроенную
SHA-256 подпись, необходимую и для тестов при включённой Memory Integrity.
Совместимость текущего ACX с HVCI ещё не проверена загрузкой. Если Windows сообщит
о несовместимости, сохраните точную ошибку устройства/Code Integrity. Для отдельного
сравнения настройка находится в **Безопасность Windows → Безопасность устройства →
Сведения об изоляции ядра → Целостность памяти**. MSI её не меняет.

На стенде при проверке: Secure Boot выключен, HVCI включён, Test Mode выключен.
Поэтому установка kernel-драйвера ещё не выполнялась. Это снимок данного ПК,
а не требования к настройке каждого компьютера.

## Что установится

- Собственный **Rey Audio Driver** и root-устройство `Root\ReyAudioAcx`.
- Автоматическая **ReyAudioService** и отдельная панель/микшер без ASIO SDK.
- Ярлык в меню Пуск, запуск панели в трее при входе в Windows.
- Собственное правило LAN: программа службы, UDP, Private, LocalSubnet.

Установщик проверяет исходные SYS/INF/CAT, создаёт уникальный локальный тестовый
сертификат, подписывает SYS и CAT встроенным механизмом Windows и проверяет
подписи и каталог. Публичная часть добавляется в Root/TrustedPublisher данного ПК.
Закрытый ключ не экспортируется и удаляется после подписания. SignTool, WDK,
интернет и покупка сертификата на пользовательском ПК не нужны.
Срок локальной подписи — два года; для обновления просроченной тестовой установки
нужно удалить её и установить свежий пакет. Первоначальные MSI/EXE не имеют
коммерческой подписи, поэтому Windows может показывать «Неизвестный издатель».

Все настройки меняются в панели: **Микшер**, **USB**, **AoIP / LAN**.
USB обнаруживается автоматически. Для LAN выберите устройство/IP в его разделе.
Оба транспортных профиля и микшер сохраняются службой в реестре Windows одним
атомарным значением; пользовательских INI нет. Изменение UDP-порта обновляет
только своё правило LAN; USB при этом не перенастраивается.

## Удаление и проверка

Удалите продукт через **Параметры → Приложения → Установленные приложения**.
Убираются собственные служба, root-устройство, автозапуск и правило firewall;
удаляется доверие только к своему локальному сертификату. Настройки и публичные
файлы диагностики сохраняются. Пакет в Driver Store может остаться для диагностики;
установщик не удаляет чужие или используемые пакеты принудительно.

Preview проверен сборкой, MSI ICE validation, извлечением и сверкой содержимого,
локальным подписанием и отказом проверки после порчи SYS. Установка/удаление
через повышенный MSI, загрузка ACX, WASAPI/DAW и физический звук пока требуют
проверки на подготовленном ПК. [Микшер и задержка](MIXER.ru.md).
