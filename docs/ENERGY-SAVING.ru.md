# Каналы, цифровая тишина и трей

Откройте **Device → Channels**, отметьте входы/выходы и нажмите **Done → Apply**. Физическое число каналов сообщает Pi. Выключенный канал сохраняет номер ASIO, но в V3 не передаёт выбранный PCM по сети. Настройки сохраняются в INI.

**Settings → Advanced → Reduce traffic during digital silence** включает две функции для V3:

- передавать пересечение вручную включённых каналов и ASIO-буферов, созданных хостом;
- исключать точный целочисленный ноль, сохраняя любое ненулевое значение PCM.

При полной тишине направления отправляются три переходных маркера, затем аудиодатаграммы прекращаются. Первый ненулевой блок возобновляет передачу в той же сессии. Пока хост держит устройство запущенным, ASIO callbacks продолжаются. При выключенной функции вручную включённые каналы передаются во время start. Штатный stop снимает подписку, аварийно покинутая V3-сессия истекает через три секунды. Keepalive и проверка устройства для трея — управляющий трафик.

Нужна поддержка V3. Pi 5 использует сервис с ожиданием подписки; Pi 4 сохраняет непрерывную legacy-обёртку. См. [V3](https://github.com/danrey-bilo/AoIP-lib/blob/main/docs/PROTOCOL-V3.ru.md).

`PiAoipControl.exe --tray` отслеживает подключение. При найденном Pi появляется значок; клик открывает настройки, контекстное меню позволяет выйти. `--quit` закрывает существующий экземпляр трея. MSI настраивает запуск при входе в Windows. В 2.5.0 встроенные значки нескольких разрешений используются в EXE, панели, трее, ярлыках и списке установленных приложений.
