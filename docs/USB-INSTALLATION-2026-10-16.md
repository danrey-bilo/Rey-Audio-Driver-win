# Установка AKM USB / ASIO — 16 октября 2026

Этот документ фиксирует исходную установку **dev.4**. Более поздние результаты
**dev.5** находятся в [отчёте задержки](USB-LATENCY-2026-10-16.md); фактическое
применение нового пакета фиксируется отдельно в `DEV5-INSTALLATION-STATUS.json`
согласованного development-пакета. Проверка временных бинарных файлов не означает
их постоянную установку.

После явного подтверждения пользователя пакет **2.8.2-akm-dev.4** установлен
на Raspberry Pi 5 и Windows. Контрольные суммы четырёх файлов Windows и четырёх
ELF Pi совпали с ранее опубликованным пакетом. Windows обнаруживает плату через
`winusb-jack`; служба запущена, ASIO DLL зарегистрирована, панель работает в трее
и её автозапуск настроен.

На Pi активны девять служб/наблюдателей, native-служба включена для автозапуска.
Проверка здоровья прошла; таймер автоматического отката снят. Резервная копия:
`/var/backups/rey-usb-20261016-1VjcKL`. Аварийный откат не запускался специально;
перезагрузка с постоянной native-службой пока не проверена.

Пресет, глобальные настройки, аппаратный микшер, восемь маршрутов каналов,
режим ПК и автономный профиль 96 кГц / 128 сохранены. Настройки gain/mute/solo/invert
микшера Windows также совпали с состоянием до установки.

Из установленной зарегистрированной ASIO DLL выполнен **60-секундный тихий
поток 8×8, 96 кГц, PCM32, ASIO 64**: код завершения 0, все счётчики потерь,
переполнений и нарушений последовательности ПК — 0. Наблюдение native Pi также
дало 0 underflow/overflow, conversion errors, JACK xruns и lease timeouts.
Дополнительно во время короткого тихого потока проверены реальные соединения
JACK всех восьми каналов: capture до эффектов, playback напрямую, режим Combined;
I/O xrun и ошибки маршрутов — 0.

Это проверка установленной системы и соединений, **не новый замер RTT**.
Значения задержки остаются результатом [предыдущей цифровой петли](USB-LATENCY-2026-10-16.md).
Аналоговая петля, многочасовая DAW-нагрузка и исправление выключения при USB-C → USB-C
не заявляются. Проверенный кабель — USB-A → USB-C напрямую к ПК.
