# Rey Audio Driver 2.6.1 preview

The home page is now **Mixer**: eight input/output controls, gain, Mute/Solo,
polarity, master output level and real PCM meters. Changes apply without a
transport restart or added PCM queue.

Install through EXE or MSI. The package adds the ACX driver, automatic service
and tray panel; settings live in the registry. The installer creates a unique
local test signature without a paid certificate or distributed private key.
Windows Test Mode is required. [Installation](INSTALL.md).

Validation: 14 contract/DSP checks, 10 finite Pi service checks, MSI ICE/CAB/hash
inspection, local signing/catalog and tamper rejection. Full elevated
installation, ACX/WASAPI and physical ADC/DAC remain unqualified. Physical USB
roundtrip <2 ms is a target, not a measured result. [Details](REY-AUDIO-2.6.md).
