# Retired Windows AoIP code

Preserved history only. Rey Audio Driver 2.8 and later builds support one USB
device. Nothing in this directory is included in CMake, the running service,
the control panel or the USB installer. LAN updates have stopped.

The independent AoIP repositories and their existing releases are unchanged.
Older installation, signing and multi-card instructions are historical and do
not apply to the USB package. The current entry point is [Rey Audio Driver](../../README.md).

This is a preservation archive, not a separately maintained or buildable SDK.
Use Git history when restoring a complete earlier source tree.
